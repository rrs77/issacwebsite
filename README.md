# Old Moulsham Tutoring

Personalised Maths and Combined Science tutoring website for Year 7–GCSE students in Chelmsford.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
